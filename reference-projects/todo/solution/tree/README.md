# To-do list

A personal to-do list for your phone: add tasks, tick them off, delete them. One user, no account.
Generated by Cobble from the `fastapi-react` template.

## Start the application

The backend serves the API (`/api/todos`) and the built web page.

    uv sync
    cd frontend && pnpm install && pnpm build && cd ..
    uv run uvicorn app.main:app --reload

Then open http://localhost:8000/. While working on the page, `pnpm dev` in the `frontend`
folder starts the Vite dev server, which forwards `/api` to the backend.

## Where the data is kept

Tasks are stored in a SQLite file, `data/todos.db` by default. Set the `TODO_DB` environment
variable to use another path. The file is ignored by git.

With `TODO_SEED=1` an empty store is filled with demo tasks when the application starts
(`python -m app.seed` does the same from the command line).

## Run the tests

    uv run pytest
    pnpm --dir frontend test

## API

- `GET /api/health`: `{"status": "ok"}`.
- `POST /api/todos` with `{"title": "..."}` (1 to 200 characters): 201 and the new todo.
- `GET /api/todos`: all todos, oldest first.
- `PATCH /api/todos/{id}` with `{"done": true}`: the updated todo.
- `DELETE /api/todos/{id}`: 204. An unknown id gives 404.
