# Cobble v0.1 — release notes and validation report

**English** · [Français](#français)

## Status

The v0.1 code is complete (plan steps 1 to 10). **Step 11 — end-to-end validation on a clean Ubuntu VM with a real inexpensive API key or Ollama — has not been done**: it needs a machine and a key the development environment did not have. `v0.1.0` is therefore **not published**. The "to fill in" cells below are for that validation.

### Known v0.1 limits

- **The full real chain (Forgejo + Woodpecker + agent-service + Aider + previews) has never been run end to end.** Its pieces were verified live separately (pack and CI-gated merge; Aider runner and agent-service; preview service), the scheduler was verified with fake implementations, and "fake pack" mode runs the whole loop in the browser tests. The harness `scripts/e2e_full.sh` (see `docs/*/e2e-full.md`) is written but **has not been run yet**: it is the first thing to do during validation.
- Plain HTTP only (no automatic HTTPS); amd64 only; no GPU/Ollama in the pack (API only).
- The preview embedded in the UI is sandboxed without `allow-same-origin`: for a demo that calls its own API, use "Open demo" (new tab).
- No `backup`/`restore`; a single worker instance.

4. Create a project, describe a to-do list app, approve the spec and plan, start building.
5. Validate the milestones in the Demo tab; note any comments.

## Statut

Le code de la v0.1 est complet (étapes 1 à 10 du plan). **L'étape 11 — validation de bout en bout sur une VM Ubuntu vierge avec une vraie clé d'API économique ou Ollama — n'a pas été faite**: elle exige une machine et une clé que l'environnement de développement n'avait pas. La version `v0.1.0` n'est donc **pas publiée**. Les cases « à remplir » ci-dessous sont à compléter lors de cette validation.

| Étape | Critère | Preuve |
|---|---|---|
| 1 | `make lint test` passe, CI verte | CI GitHub Actions |
| 2 | `make dev` sans clé d'API; réponse de cassette via LiteLLM; coût et jetons en base | `make smoke`, job CI `core-stack` |
| 3 | Activation, connexion, dossier et projet, FR/EN et clair/sombre sans rechargement | e2e Playwright (`shell.spec.ts`) |

### Limites connues de la v0.1

- **La chaîne complète réelle (Forgejo + Woodpecker + agent-service + Aider + aperçus) n'a jamais été exécutée d'un bout à l'autre.** Ses morceaux ont été vérifiés séparément en direct (pack et fusion conditionnée à la CI; runner Aider et agent-service; service d'aperçu), l'ordonnanceur l'a été avec des implémentations factices, et le mode « faux pack » fait tourner la boucle complète dans les tests navigateur. Le harnais `scripts/e2e_full.sh` (voir `docs/*/e2e-full.md`) est écrit mais **n'a pas encore été lancé**: c'est la première chose à faire lors de la validation.
- HTTP seulement (pas de HTTPS automatique); amd64 seulement; pas de GPU/Ollama dans le pack (API seulement).
- L'aperçu intégré à l'UI est sandboxé sans `allow-same-origin`: pour une démo qui appelle sa propre API, utiliser « Ouvrir la démo » (nouvel onglet).
- Pas de `backup`/`restore`; une seule instance de worker.
