# Cobble

**Français** · [English](#english)

Cobble est une plateforme libre et auto-hébergée qui transforme une idée en application: un chat planifie, des agents peu coûteux codent dans des conteneurs isolés, la CI arbitre, et vous validez une démo.

> **État**: v0.1 en développement (« la boucle fonctionne », pack fixe). Pas encore utilisable. Voir [PLAN.md](PLAN.md) et [CHANGELOG.md](CHANGELOG.md).

## English

Cobble is a free, self-hosted platform that turns an idea into an application: a chat plans the work, inexpensive agents code in isolated containers, CI is the referee, and you approve a demo.
