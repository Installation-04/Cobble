# Sécurité / Security

## Français

Ne signalez pas une faille dans une issue publique. Utilisez les **avis de sécurité privés** de GitHub (onglet *Security* → *Report a vulnerability*) du dépôt.

Nous visons un accusé de réception sous 5 jours ouvrables et une correction ou un plan sous 90 jours. Seule la dernière version publiée est supportée tant que Cobble est en 0.x.

## English

Do not report a vulnerability in a public issue. Use the repository's **private GitHub security advisories** (*Security* tab → *Report a vulnerability*).

We aim to acknowledge within 5 business days and to ship a fix or a plan within 90 days. While Cobble is 0.x, only the latest release is supported.
